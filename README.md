# nbki_smoke_tester
Анализатор smoke-тестов

Инструкция

Подготовленые тестовые файлы в версии xsd-схемы 5.0 скопировать (сразу все) в папку rutdf

Скачать лог-файл текущих суток /opt/nbki/loader-manager/logs/loader-trace.log

Запустить скрипт (или smoke.exe)

В открывшемся окне указать путь для файла loader-trace.log
